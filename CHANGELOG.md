# История изменений Steam Focus Guard

## Beta 0.1 — первоначальный прототип

Первая рабочая версия была сосредоточена на базовой идее: не позволять запускать Steam, пока пользователь не выбрал разрешённый режим.

- Обнаружение процесса `steam.exe` с периодической проверкой примерно раз в 250 мс.
- Принудительное завершение Steam, если он запущен без разрешения.
- Главное окно с основными действиями для начала занятий, временного доступа и открытия Steam после выполнения учебных условий.
- Неограниченный доступ к Steam до закрытия игры.
- Временный доступ на 30 минут: предупреждения за 5 и 1 минуту до окончания, затем закрытие Steam.
- Настраиваемый учебный план и тексты интерфейса через `config.json`.
- Возможность добавлять защитник в автозагрузку Windows и удалять его оттуда.
- Журнал событий в CSV.
- Сохранение состояния временного доступа, чтобы перезапуск защитника не обнулял оставшееся время.

Начальное расписание было ориентировано на учебную неделю: университетские задания, Python, SQL, закрытие накопившихся задач, гибкий день в субботу и отдых в воскресенье.

> Уточнение по нумерации: в ранней переписке первоначальная версия также называлась 1.0. Обозначение Beta 0.1 здесь используется ретроспективно — как название самого первого прототипа для истории релизов.

> Примечание по истории: доступный первоначальный коммит GitHub содержит только заголовок README. Поэтому этот список описывает раннюю функциональную версию по истории разработки, а не diff отдельного тега Beta 0.1.

## Текущая версия до рефакторинга

По сравнению с первоначальным прототипом проект получил более гибкое расписание и отдельную проверку дневной нормы.

- Недельное расписание с отдельными задачами на каждый день.
- Особые планы на конкретные даты через `schedule.special_dates`.
- Индивидуальная норма учебного времени для каждого дня недели: 90 минут с понедельника по пятницу, 60 минут в субботу и 0 минут в воскресенье.
- Кнопка «Проверить» показывает прошедшее время и остаток до дневной нормы; после выполнения нормы открывает неограниченный доступ.
- Более подробная настройка поведения, размеров окна, параметров обнаружения Steam и всех пользовательских текстов через JSON.
- Сохранение состояния защитника и остатка временного таймера при перезапуске.
- Более подробный CSV-журнал событий.
- Документация уточняет ограничение механизма учёта: он считает обычное прошедшее время с момента начала сессии, но не проверяет реальную учебную активность и не ставится на паузу при бездействии.
- Описаны установка, запуск, автозагрузка, остановка и редактирование конфигурации.

## Рефакторинг

Работы по рефакторингу ведутся в отдельной ветке. Изменения структуры не должны менять пользовательскую логику блокировки Steam.

## Рефакторинг — подготовительный этап

### Добавлено (Added)
- Разделение исходного кода на модули: конфигурация, пути и миграция данных, журнал, расписание, поиск Steam, автозагрузка, контроллер и точка входа.
- Каталоги `config/`, `data/`, `scripts/`, `docs/` и шаблон `config/config.example.json`.
- Отдельное окно «Настройки» с вкладками расписания, параметров Steam и приложения, а также текстов интерфейса.
- Визуальное редактирование задач и дневных норм по дням недели; добавление, удаление и изменение порядка задач.
- Резервные копии конфигурации перед сохранением и отдельная команда создания копии вручную.
- Кнопка «Сбросить таймер» с подтверждением.
- Таймер в главном окне с обновлением каждую секунду.

### Изменено (Changed)
- Активная конфигурация хранится в `config/config.json`, шаблон — в `config/config.example.json`.
- Состояние, CSV-журнал и служебные файлы размещаются в `data/`.
- Добавлены BAT-сценарии в `scripts/`; старые запускатели в корне сохранены для совместимости.
- Окно настроек применяет изменения после сохранения без перезапуска защитника.

### Исправлено (Fixed)
- Миграция старых файлов выполняется копированием и не перезаписывает существующие новые файлы.
- Исправлена обработка переключения дней в редакторе расписания, чтобы задачи одного дня не попадали в другой.
- Устранено создание дополнительных циклов обновления таймера при ручном сбросе и применении настроек.

### Удалено (Removed)
- Кнопка «Всё сделано — открыть Steam» удалена. Её функция проверки полностью заменена кнопкой «Проверить».

### Известные ограничения (Known Issues)
- Визуальное редактирование особых дат пока не реализовано; существующие особые даты сохраняются и продолжают учитываться.
- Необходима проверка работы графического интерфейса и миграции на Windows перед публикацией стабильного релиза.

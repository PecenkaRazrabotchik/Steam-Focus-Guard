# Steam Focus Guard

Небольшая Windows-программа на Python, которая отслеживает запуск `steam.exe`, закрывает Steam при отсутствии разрешения и показывает окно с учебным расписанием.

> **Важно:** это не системная блокировка. Защитник обнаруживает процесс примерно каждые 250 мс и завершает его, поэтому Steam может кратковременно появиться. Пользователь с правами администратора или достаточными техническими знаниями может остановить защитник.

## Возможности

- Недельное расписание с отдельными задачами на каждый день.
- Отдельный план на конкретную дату через `special_dates`.
- Редактируемые надписи, кнопки и уведомления в `config.json`.
- Режим «Сначала выполню задания» — Steam остаётся заблокированным.
- Кнопка «Проверить» сверяет учебное время с дневной нормой из конфигурации и открывает Steam без ограничения после её выполнения.
- Временный доступ на 30 минут с предупреждениями на 25-й и 29-й минутах.
- Неограниченный доступ до закрытия Steam.
- Сохранение остатка таймера при перезапуске защитника.
- Журнал событий в CSV.
- Автозапуск Windows по желанию.

## Установка

1. Скачай репозиторий: **Code → Download ZIP**, затем распакуй его в постоянную папку, например `C:\Tools\SteamFocusGuard`.
2. Установи Python 3.10 или новее для Windows. При установке включи Python Launcher (`py`).
3. Запусти `install_requirements.bat`.
4. Запусти `start_guard.bat` и проверь работу вручную.
5. Только после тестирования запусти `install_startup.bat`, чтобы добавить защитник в автозагрузку текущего пользователя.

Для удаления из автозагрузки запусти `remove_startup.bat`. Для остановки уже работающего защитника — `stop_guard.bat`.

## Настройка

Открой `config.json` в Блокноте или VS Code.

- `schedule` — задачи с понедельника по воскресенье.
- `schedule.special_dates` — особое расписание на конкретную дату в формате `YYYY-MM-DD`.
- `ui` — все пользовательские тексты.
- `app` — путь к Steam, интервал проверки, размеры окна и другие технические параметры.
- `rules.required_study_minutes` — дневная норма по умолчанию (в текущем расписании 90 минут).
- `schedule.<день>.required_study_minutes` — норма для конкретного дня; она переопределяет общее значение. Сейчас задано 90 минут с понедельника по пятницу, 60 минут в субботу и 0 минут в воскресенье.
- Кнопка **«Проверить»** показывает прошедшее и оставшееся время. Когда дневная норма выполнена, она выдаёт неограниченный доступ к Steam. Кнопка «Всё сделано» проходит ту же проверку.

После редактирования `config.json` перезапусти защитник. JSON не допускает комментарии и лишние запятые.

## Файлы и данные

- `steam_focus_guard.py` — основная программа.
- `config.json` — расписание, тексты и настройки.
- `requirements.txt` — зависимости Python.
- `*.bat` — команды установки, запуска и управления.
- `state.json` — локальное состояние и оставшееся время таймера.
- `activity_log.csv` — локальный журнал событий.
- `guard.lock` и `stop.request` — служебные файлы.

Локальные файлы состояния и журнал исключены из Git через `.gitignore`.

## Контроль обучения

Программа считает обычное прошедшее время с момента нажатия «Сначала выполню задания». Она не измеряет активность клавиатуры и мыши и не ставит таймер на паузу, если отойти от компьютера или оставить его без дела. Поэтому этот механизм подтверждает длительность сессии, но не доказывает, что всё это время действительно шла учёба. Для более полезной самопроверки фиксируй результат: решённые задачи, написанные SQL-запросы, Git-коммиты или выполненные университетские задания.

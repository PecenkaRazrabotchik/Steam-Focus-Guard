# Steam Focus Guard

Небольшая Windows-программа на Python, которая отслеживает запуск `steam.exe`, закрывает Steam при отсутствии разрешения и показывает окно с учебным расписанием.

> **Важно:** это не системная блокировка. Защитник обнаруживает процесс примерно каждые 250 мс и завершает его, поэтому Steam может кратковременно появиться. Пользователь с правами администратора или достаточными техническими знаниями может остановить защитник.

## Возможности

- Недельное расписание и особые планы на конкретные даты.
- Визуальное окно «Настройки» для изменения недельного расписания, дневных норм, параметров приложения и текстов интерфейса.
- Кнопка «Проверить» — проверяет выполнение дневной нормы; отдельной кнопки «Всё сделано» больше нет.
- Кнопка «Сбросить таймер» — сбрасывает учебную сессию после подтверждения.
- Таймер в верхней части окна обновляется каждую секунду: показывает учебное время и дневную норму либо остаток временного игрового доступа.
- Временный доступ на 30 минут с предупреждениями на 25-й и 29-й минутах.
- Неограниченный доступ до закрытия Steam.
- Сохранение остатка таймера при перезапуске защитника.
- Журнал событий в CSV.
- Автозапуск Windows по желанию.

## Установка

1. Скачай репозиторий: **Code → Download ZIP**, затем распакуй его в постоянную папку, например `C:\Tools\SteamFocusGuard`.
2. Установи Python 3.10 или новее для Windows. При установке включи Python Launcher (`py`).
3. Запусти `scripts\install_requirements.bat`.
4. Запусти `scripts\start.bat` и сначала проверь работу вручную.
5. Только после тестирования запусти `scripts\install_startup.bat`, чтобы добавить защитник в автозагрузку текущего пользователя.

Для удаления из автозагрузки запусти `scripts\remove_startup.bat`. Для остановки уже работающего защитника — `scripts\stop.bat`.

Старые BAT-файлы в корне проекта сохранены как совместимые запускатели для прежних ярлыков и инструкций.

## Настройка

Открой главное окно и нажми **«Настройки»**.

- Вкладка **«Расписание»** позволяет выбрать день недели, задать дневную норму, добавлять, удалять и перемещать задачи.
- Вкладка **«Steam и приложение»** позволяет задать путь к `steam.exe`, интервал проверки, задержку закрытия, размеры окна и поведение запуска.
- Вкладка **«Тексты интерфейса»** позволяет менять надписи и сообщения программы.
- Перед сохранением активной конфигурации создаётся резервная копия в `config/backups/`.
- Кнопка **«Сбросить настройки»** возвращает встроенные значения по умолчанию; сброс вступает в силу только после нажатия «Сохранить».

Особые даты из `schedule.special_dates` сохраняются и учитываются программой, но в этой версии их редактирование пока выполняется непосредственно в JSON-файле.

## Структура проекта

- `main.py` — точка входа приложения.
- `src/` — исходный код: контроллер Steam, настройки, расписание, хранилище, пути и автозагрузка.
- `src/ui/` — окна пользовательского интерфейса.
- `config/config.example.json` — шаблон конфигурации, поставляемый с программой.
- `config/config.json` — активные пользовательские настройки, создаваемые при первом запуске.
- `data/` — состояние программы, журнал и служебные файлы.
- `scripts/` — сценарии установки и управления.
- `docs/` — дополнительная документация.
- `requirements.txt` — зависимости Python.

## Миграция со старой структуры

При первом запуске новая версия создаёт каталоги `config/`, `data/`, `scripts/` и `docs/`.

- Старый `config.json` из корня копируется в `config/config.json`, если новый активный файл ещё не существует.
- Старые `state.json`, `activity_log.csv`, `guard.lock` и `stop.request` копируются в `data/`, только если целевые файлы отсутствуют.
- Исходные старые файлы не удаляются и не перезаписываются.
- Если активная конфигурация уже существует, миграция её не заменяет.

## Контроль обучения

Программа считает обычное прошедшее время с момента нажатия «Сначала выполню задания». Она не измеряет активность клавиатуры и мыши и не ставит таймер на паузу, если отойти от компьютера или оставить его без дела. Поэтому этот механизм подтверждает длительность сессии, но не доказывает, что всё это время действительно шла учёба.

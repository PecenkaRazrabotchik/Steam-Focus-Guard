# Focus Guard

**Focus Guard** — настольное приложение для Windows, которое помогает планировать дела, отслеживать время фокус-сессий и ограничивать отвлекающие приложения и сайты.

Вместо заранее заданного расписания пользователь сам формирует список задач: задаёт их фокус, статус, срочность, категорию и продолжительность. Главное окно объединяет планирование, поиск, фильтры и статистику в одном интерфейсе.

> **Состояние проекта:** приложение находится в активной разработке. Перед использованием блокировок рекомендуется проверить настройки на своём компьютере.

## Возможности

### Планирование задач

- Создание, редактирование и удаление задач.
- Три уровня фокуса:
  - **Главная** — синий цвет; задачи отображаются первыми.
  - **Дополнительная** — жёлтый цвет.
  - **Пока подождёт** — серый цвет; задачи отображаются последними.
- Статусы: **К выполнению**, **В работе**, **Выполнено**.
- Срочность: **Срочно**, **Высокая**, **Средняя**, **Низкая**.
- Категории: работа, учёба, личное, встречи и пользовательские категории.
- Индивидуальная продолжительность каждой задачи.
- Отдельные планы для дней недели и навигация по датам.

### Главная панель

- Статистика: всего задач, выполнено, в работе и срочные.
- Поиск по названию и категории.
- Фильтры по статусу, срочности и категории.
- Карточки задач с цветовым индикатором срочности.
- Трёхколоночная сетка карточек в тёмной теме.

### Фокус-таймер

- Запуск, пауза, продолжение и сброс таймера.
- Пауза не засчитывается в прошедшее учебное время.
- Целевая продолжительность рассчитывается как сумма длительностей задач выбранного дня.
- Кнопка **«Проверить задачи»** сравнивает прошедшее время с запланированным.
- После выполнения плана можно открыть Steam; доступ сохраняется до закрытия Steam.

Таймер фиксирует время запущенной сессии, но не измеряет активность клавиатуры и мыши. Он не может подтвердить, что пользователь действительно занимался всё это время.

### Ограничение приложений и сайтов

- Пользовательский список приложений Windows по именам процессов, например `Discord.exe` или `Telegram.exe`.
- Ограничения приложений действуют в режиме блокировки и во время фокус-сессии; после выполнения плана они приостанавливаются.
- Блокировка сайтов по доменам через управляемую секцию системного файла Windows `hosts`.
- Применение правил сайтов требует подтверждения UAC и прав администратора.

**Ограничения блокировок:**
- Блокировка приложений основана на завершении процессов и действует только пока запущен Focus Guard. Это не системная политика Windows.
- Блокировка сайтов охватывает указанный домен и его вариант `www`, но не все поддомены автоматически.
- VPN, собственный DNS или DNS-over-HTTPS могут обходить блокировку через `hosts`.
- Focus Guard изменяет только собственную секцию с маркерами и сохраняет остальные строки файла `hosts`.

### Windows и системный трей

- Значок в системном трее с командами открытия приложения, паузы/продолжения и выхода.
- Возможность сворачивать окно в трей.
- Настройка запуска приложения вместе с Windows для текущего пользователя.
- Настройка пути к `steam.exe`, автоматического запуска Steam и задержки повторной блокировки.

## Получение приложения

### Готовая Windows-сборка

Готовая сборка публикуется как artifact **FocusGuard-Windows** в GitHub Actions:

1. Открой страницу [Windows desktop build](https://github.com/PecenkaRazrabotchik/Steam-Focus-Guard/actions/workflows/windows-build.yml).
2. Выбери последний успешный запуск workflow.
3. Внизу страницы скачай artifact `FocusGuard-Windows`.
4. Распакуй ZIP целиком в постоянную папку.
5. Запусти `FocusGuard.exe` внутри папки `FocusGuard`.

Сборка создаётся в формате **onedir**. Не перемещай EXE отдельно от остальных файлов и сохрани рядом каталоги `config` и `data`.

### Запуск из исходного кода

Требуется Windows и Python 3.10 или новее.

1. Скачай ZIP репозитория и распакуй его в постоянную папку.
2. Установи зависимости:

   ```powershell
   py -m pip install -r requirements.txt
   ```

3. Запусти приложение:

   ```powershell
   py main.py
   ```

Для создания собственной EXE-сборки запусти:

```text
scripts\build_windows.bat
```

Готовая папка появится в `dist\FocusGuard\`.

## Настройки и данные

Основные параметры доступны через кнопку **«Настройки»**:

- **Приложения** — список процессов, которые нужно ограничивать.
- **Сайты** — список доменов и включение блокировки через hosts.
- **Приложение** — системный трей, автозапуск, поведение окна, путь к Steam и параметры проверки.

Данные хранятся отдельно от исходного кода:

| Путь | Назначение |
|---|---|
| `config/config.json` | Активные пользовательские настройки и задачи |
| `config/config.example.json` | Шаблон настроек |
| `config/backups/` | Резервные копии конфигурации |
| `data/state.json` | Состояние приложения и таймера |
| `data/activity_log.csv` | Журнал событий |
| `data/hosts-before-focus-guard.bak` | Резервная копия hosts перед первым изменением |

При переходе со старой структуры файлы настроек и данных копируются в новые каталоги, если целевые файлы ещё не существуют. Старые файлы не удаляются.

## Проверка проекта

Автоматические проверки запускаются через GitHub Actions:

- [Python validation](https://github.com/PecenkaRazrabotchik/Steam-Focus-Guard/actions/workflows/python-validation.yml) — компиляция Python-файлов, тесты и проверка JSON-конфигурации.
- [Windows desktop build](https://github.com/PecenkaRazrabotchik/Steam-Focus-Guard/actions/workflows/windows-build.yml) — сборка Windows-приложения и публикация artifact.

Локальный запуск тестов:

```powershell
py -m compileall -q main.py src tests
py -m unittest discover -s tests -v
```

## Структура проекта

- `main.py` — точка входа.
- `src/` — логика приложения, таймер, задачи, настройки, блокировки и системный трей.
- `src/ui/` — графические окна.
- `config/` — шаблон и пользовательская конфигурация.
- `data/` — состояние и журнал.
- `scripts/` — запуск, установка зависимостей и сборка.
- `docs/` — техническая документация.
- `tests/` — автоматические тесты.

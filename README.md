# Focus Guard

Focus Guard — Windows desktop-приложение для планирования задач и ограничения отвлекающих программ и сайтов во время фокус-сессии.

Приложение использует Python, CustomTkinter, psutil и системный трей Windows. Для самостоятельной сборки в `.exe` используется PyInstaller.

## Основные возможности

- Современный тёмный интерфейс с карточками задач и скруглёнными элементами.
- Добавление задач с приоритетом, описанием и собственной длительностью.
- Три уровня фокуса:
  - **Главная** — синий цвет, отображается первой.
  - **Дополнительная** — жёлтый цвет, отображается после главных.
  - **Пока подождёт** — серый цвет, отображается последней.
- Задачи автоматически сортируются по приоритету; порядок внутри каждой группы сохраняется.
- Изначальный список задач пустой. Пользователь самостоятельно составляет план.
- Учебный таймер суммирует длительность задач, поддерживает паузу и продолжение.
- После достижения суммарного запланированного времени кнопка «Проверить задачи» может открыть Steam до закрытия игры.
- Блокировка выбранных приложений по имени процесса.
- Блокировка доменов через управляемый раздел файла Windows hosts.
- Системный трей: открыть приложение, поставить таймер на паузу или выйти.
- Настройка автозапуска приложения вместе с Windows.
- Миграция прежнего текстового расписания в новый формат задач без намеренного удаления пользовательских записей.

## Установка и запуск из исходного кода

1. Установи Python 3.10 или новее для Windows.
2. Скачай ZIP репозитория и распакуй его в постоянную папку.
3. Выполни `scripts\\install_requirements.bat` или команду `py -m pip install -r requirements.txt`.
4. Запусти `py main.py`.

Для остановки запущенного приложения можно использовать `py main.py --stop` или пункт «Выход» в меню системного трея.

## Сборка в Windows-приложение

Запусти `scripts\\build_windows.bat`.

После успешной сборки исполняемый файл будет находиться здесь:

`dist\\FocusGuard\\FocusGuard.exe`

Папки `config` и `data` должны располагаться рядом с исполняемым файлом. Сборка создаётся в формате onedir, поэтому не следует переносить только EXE отдельно от остальных файлов в каталоге.

## Задачи и таймер

При добавлении задачи выбери приоритет, введи название и задай длительность в часах и минутах. Карточка задачи показывает цветной приоритет, название и плановое время. Список группируется в порядке: главные, дополнительные, ожидающие.

Сумма длительностей задач формирует дневную цель. Таймер считает время активной фокус-сессии; интервалы паузы не учитываются. Приложение не измеряет активность клавиатуры и мыши, поэтому не может доказать, что пользователь всё это время занимался.

Задачи хранятся отдельно для каждого дня недели. По умолчанию все дни пустые. Старые текстовые задачи при загрузке преобразуются в новый формат: префиксы вроде «Главное» и «Дополнительно» используются для определения приоритета, длительность распознаётся из текста, если она указана.

## Блокировка приложений

Открой **Настройки → Приложения** и введи имена процессов, по одному на строку, например:

```text
Discord.exe
Telegram.exe
```

Focus Guard обнаруживает такие процессы и завершает их во время работы приложения. Это не системная политика Windows: если закрыть Focus Guard, блокировка приложений перестанет действовать. Для безопасности нельзя добавлять критические системные процессы или сам исполняемый файл Focus Guard.

## Блокировка сайтов

Открой **Настройки → Сайты**, включи блокировку и добавь домены без URL-пути:

```text
youtube.com
reddit.com
```

При сохранении Windows запросит подтверждение UAC. Приложение добавляет только собственный размеченный раздел в системный файл hosts и сохраняет остальные строки. DNS-кэш обновляется после применения правил.

**Важно:**
- Для изменения hosts необходимы права администратора Windows.
- В текущей версии блокируются указанный домен и его вариант `www`; отдельные поддомены могут потребовать отдельного добавления.
- Правила hosts остаются активными после закрытия Focus Guard и отключаются после снятия флажка в настройках и повторного подтверждения UAC.
- Блокировка через hosts не заменяет сетевой фильтр и может обходиться приложениями с собственным DNS-over-HTTPS или VPN.

## Системный трей и автозапуск

В **Настройки → Приложение** доступны:
- **Показывать значок в системном трее** — включает значок и меню управления.
- **Запускать приложение вместе с Windows** — добавляет обычную запись для текущего пользователя в реестр Windows.
- **Сворачивать в трей при закрытии окна** — закрытие окна не завершает защиту.
- **Показывать окно поверх других окон**.
- Интервал проверки процессов.

Автозапуск можно отключить в том же разделе настроек. Запись создаётся только в профиле текущего пользователя.

## Данные и безопасность

- `config/config.json` — пользовательские настройки и задачи.
- `config/config.example.json` — чистый шаблон конфигурации.
- `config/backups/` — резервные копии перед сохранением.
- `data/state.json` — состояние таймера и приложения.
- `data/activity_log.csv` — журнал событий.
- `data/hosts-before-focus-guard.bak` — исходная копия hosts, сделанная перед первым изменением.

Файл hosts изменяется только внутри маркеров Focus Guard. При отключении блокировки удаляется только этот раздел. Другие строки файла не должны изменяться приложением.

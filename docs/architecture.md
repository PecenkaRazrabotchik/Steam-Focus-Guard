# Архитектура проекта

Приложение использует Python и Tkinter. Точка входа — `main.py`.

## Модули

- `src/app.py` — обработка аргументов командной строки, проверка зависимости `psutil`, блокировка второго экземпляра и запуск главного окна.
- `src/steam_focus_guard.py` — контроллер приложения: состояние доступа, интерфейс главного окна, таймеры и мониторинг процессов Steam.
- `src/config_manager.py` — встроенные значения, объединение настроек по умолчанию с пользовательской конфигурацией и загрузка JSON.
- `src/paths.py` — единые пути проекта, создание каталогов и безопасное копирование файлов старой структуры.
- `src/scheduler.py` — выбор расписания на день, особых дат и дневной нормы.
- `src/storage.py` — атомарная запись JSON-состояния и CSV-журнал.
- `src/steam_utils.py` — поиск исполняемого файла Steam.
- `src/startup.py` — добавление и удаление записи автозапуска Windows.
- `src/ui/settings_window.py` — визуальное окно редактирования расписания, параметров приложения и текстов.

## Поток запуска

1. `main.py` передаёт управление в `src.app.main()`.
2. Приложение создаёт структуру каталогов и копирует старые пользовательские данные, если новые файлы ещё не существуют.
3. Загружается активная конфигурация из `config/config.json`.
4. Проверяется зависимость `psutil`, устанавливается блокировка второго экземпляра и запускается главное окно.
5. Контроллер периодически проверяет процессы Steam и обновляет интерфейсные таймеры.

## Принципы хранения

- `config/config.example.json` — шаблон, который поставляется с программой.
- `config/config.json` — пользовательская конфигурация; не добавляется в Git.
- `data/state.json` и `data/activity_log.csv` — локальные данные; не добавляются в Git.
- Резервные копии конфигурации хранятся в `config/backups/`.

При миграции старые файлы копируются, а не перемещаются. Существующий файл назначения всегда имеет приоритет, поэтому новая версия не перезаписывает уже созданные пользовательские данные.

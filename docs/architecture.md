# Архитектура Focus Guard

## Технологии

- Python 3.10+
- CustomTkinter — графический интерфейс desktop-приложения.
- psutil — обнаружение и завершение выбранных процессов.
- pystray + Pillow — значок и меню системного трея.
- Windows Registry — автозапуск текущего пользователя.
- Windows hosts — опциональная блокировка доменов с UAC.
- PyInstaller — сборка переносимой onedir-версии приложения.
- GitHub Actions на Windows runner — автоматическая сборка EXE и публикация artifact.

## Основные модули

- `main.py`, `src/app.py` — точка входа, singleton приложения и команды обслуживания.
- `src/steam_focus_guard.py` — главное окно, таймер фокуса и цикл enforcement.
- `src/task_manager.py` — нормализация задач, приоритеты и сортировка.
- `src/scheduler.py` — выбор списка задач для текущего дня.
- `src/config_manager.py` — схема настроек, миграция и сохранение.
- `src/ui/settings_window.py` — пользовательские ограничения, трей и автозапуск.
- `src/website_blocker.py` — безопасная синхронизация маркированной секции hosts.
- `src/tray.py` — интеграция с системным треем.
- `src/startup.py` — запись и удаление автозапуска.
- `src/storage.py` — журнал событий и состояние.
- `src/paths.py` — пути исходной и frozen-сборки.

## Правила enforcement

Цикл приложения периодически сканирует процессы. Steam блокируется, пока пользователь не выполнил суммарную длительность задач и не подтвердил выполнение плана. Пользовательские приложения из списка ограничений завершаются по имени процесса. Эти правила действуют только во время работы Focus Guard.

Правила сайтов применяются отдельно через Windows hosts. Для изменения файла требуется UAC; Focus Guard меняет только собственную секцию с маркерами и сохраняет соседние записи.

## Данные

Активная конфигурация хранится отдельно от шаблона и кода. Frozen-сборка использует каталог рядом с EXE, чтобы обновление приложения не требовало записи в временную папку PyInstaller.

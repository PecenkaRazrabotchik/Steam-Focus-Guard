# Конфигурация Focus Guard

## Пользовательские задачи

Активная конфигурация находится в `config/config.json`. Шаблон — `config/config.example.json`.

Задачи хранятся в `schedule` отдельно по дням недели. Новая запись имеет вид:

```json
{
  "id": "уникальный идентификатор",
  "focus": "main",
  "text": "Подготовить отчёт",
  "duration_minutes": 45
}
```

Допустимые значения `focus`:
- `main` — главная задача, синяя метка.
- `additional` — дополнительная задача, жёлтая метка.
- `later` — пока подождёт, серая метка.

Список сортируется по приоритету; исходный порядок задач внутри одного приоритета сохраняется. Дневная цель таймера — сумма `duration_minutes` текущего дня.

## Правила блокировки

В разделе `rules` находятся:
- `blocked_apps` — список имён процессов Windows, например `Discord.exe`.
- `blocked_websites` — список доменов без URL-путей.
- `website_blocking_enabled` — признак применения списка сайтов в hosts.

Блокировка приложений работает, пока работает Focus Guard. Блокировка сайтов изменяет только маркированный раздел системного hosts и требует UAC.

## Настройки приложения

В разделе `app`:
- `show_in_tray` — показывать значок в системном трее.
- `start_with_windows` — запускать приложение при входе текущего пользователя.
- `close_to_tray` — скрывать окно в трей вместо выхода.
- `always_on_top` — закреплять окно поверх других окон.
- `scan_interval_ms` — интервал проверки процессов в миллисекундах.

Эти параметры доступны и через графическое окно настроек.

## Таймер и журнал

Состояние фокус-сессии сохраняется в `data/state.json`. В него записывается накопленное время и момент последнего продолжения, поэтому приостановленная сессия может быть восстановлена после перезапуска. Активный интервал, который не был сохранён перед аварийным завершением, может быть потерян.

События записываются в `data/activity_log.csv`.

## Блокировка сайтов: важные детали

Focus Guard создаёт секцию между маркерами:

- `# >>> FOCUS GUARD MANAGED WEBSITE BLOCKS >>>`
- `# <<< FOCUS GUARD MANAGED WEBSITE BLOCKS <<<`

Синхронизация удаляет прежнюю секцию Focus Guard и создаёт новую, сохраняя содержимое до и после неё. Первый исходный hosts-файл копируется в `data/hosts-before-focus-guard.bak`. Не удаляй резервную копию вручную, пока не уверен, что она больше не нужна.

В блоклист добавляется указанный домен и вариант `www`. Поддомены не подхватываются автоматически. Для снятия блокировки отключи её в интерфейсе и подтверди запрос UAC.

## Миграция

Старые текстовые задачи преобразуются в новую структуру. Префиксы «Главное», «Дополнительно» и «По желанию» определяют приоритет; длительность распознаётся, если в старом тексте было указано число минут. Пользовательские задачи сохраняются, а стандартный шаблон больше не содержит готового списка.

Системные файлы и существующие пользовательские настройки не должны перезаписываться шаблоном.
